# SwiftUI UI 规范

## 主窗口布局

采用 NavigationSplitView 左右分栏：
- **左侧**：侧边栏导航（快捷修改、卡牌管理、人物属性、计数器、仪式、全局数据）
- **右侧**：对应功能的内容区
- **标题栏**：显示修改状态（"已修改 ·"）和保存按钮

## 状态管理

- 未保存修改时标题栏显示"已修改 ·"，保存按钮高亮
- 保存成功后短暂显示"已保存"提示
- 存档加载中显示加载动画
- 未找到存档时显示引导提示

## 交互规范

- 快捷修改按钮：点击 → 确认对话框 → 执行 → 成功提示
- 删除操作：选中 → 确认对话框 → 执行
- 危险操作（直接胜利、清空等）：二次确认
- 快捷修改按钮执行后短暂禁用，防止重复点击

## 通用组件

- **CardPickerView**：通用卡牌选择器，支持类别筛选和搜索，用于添加卡牌、替换卡牌等场景
- 计数器按作用域前缀分组显示（7000=局内, 7100=跨局, 7200=成就, 7220=完成, 7230=解锁）

## 输入约束

- 属性值范围 0-999，输入框限制范围，超范围时显示警告
- 数值输入使用 Stepper（`[-] 数值 [+]`）+ 直接输入

## 降级显示

游戏配置文件未加载时，卡牌和计数器只显示 ID 不显示名称，功能不受影响。
